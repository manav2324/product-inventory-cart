
# ShopSphere - Product Inventory & Shopping Cart

A responsive product inventory and shopping cart application developed using React for the Semester 5 AWT practical assignment at GSFC University.

## Features

- Display products with ID, name, category, price, quantity, and image
- Search products by name
- Filter products by category
- View individual product details
- Add products to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- Calculate the total price dynamically
- Navigate between pages using React Router
- Responsive design for desktop and mobile

## Technologies Used

- React
- JavaScript ES6
- JSX
- React Router
- HTML5
- CSS3
- Vite

## Installation and Setup

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.
